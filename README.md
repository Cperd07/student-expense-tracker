# Student Expence Tracker💰

A simple C++ project to help students track their daily expenses.

## Features
- Add daily expenses
- View all recorded expenses
- Calculate total spending
- Simple menu-driven interface

## Technologies Used
- C++
- VS Code

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the C++ source file.
4. Run the generated program.

## Purpose
This project was created to practice C++ programming and build my developer portfolio.
